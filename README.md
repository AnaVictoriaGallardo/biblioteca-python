# Sistema de gestión de biblioteca en Python

## Descripción
Este proyecto consiste en un programa desarrollado en Python para administrar un catálogo de libros de una biblioteca.

## Funcionalidades
- Registrar nuevos libros en el catálogo.
- Buscar libros por género literario.
- Buscar libros por autor.
- Calcular el valor total del inventario.
- Almacenar información sobre títulos, autores, disponibilidad y precios.

## Tecnologías y conceptos utilizados
- Python 3
- Listas y diccionarios
- Conjuntos (`set`)
- Funciones
- Comprensiones de listas
- Funciones de entrada y salida

## Ejecución
1. Descargar el archivo `biblioteca.py`.
2. Tener Python 3 instalado.
3. Ejecutar el programa desde una terminal:

   `python biblioteca.py`
